# 1. Record architecture decisions

- Status: Accepted
- Date: 2026-11-17
- Context: The project mixes our own code with a reference copy of egon.io, so the reasons behind design choices get lost quickly.
- Decision: We keep short ADRs in `docs/adr`, one decision per file, numbered in order.
- Consequences: A new contributor or agent can read the folder in a few minutes and see why the code looks the way it does.
